## 六、2025年獲獎團隊分析與推測

> ⚠️ 以下為基於公開資訊的合理推測，2025年獲獎團隊的具體作品主題未公開發表論文。

### 6.1 已知資訊

- **團隊挑戰賽評審標準**：以「生物數據分析為核心」
- 團隊需基於主辦方提供的數據包進行分析
- 作品形式：A0學術海報 + 科普短片（≤5分鐘）+ 物種空間分布圖（300dpi）
- 要求提出「保護本澳生物多樣性和生態環境的建議」

### 6.2 2025年數據包特徵

| 特徵 | 2025年 |
|------|--------|
| 數據量 | ~33,571條記錄 |
| 物種數 | ~2,994種 |
| 植物佔比 | 75.9% |
| 觀察日期 | 4月25日-28日（4天） |
| 圈養/栽培比例 | 17% |

### 6.3 可能的獲獎策略推測

基於比賽要求和評審配置（梁志文博士為生態學專家），推測獲獎作品可能具有以下特徵：

1. **數據分析深度 > 數據收集廣度**：團隊賽數據已提供，重點在分析而非收集
2. **創新的分析方法**：可能使用了多變量統計、空間分析等進階方法
3. **清晰的保護建議**：從數據中提煉出可操作的保育對策
4. **高質量的視覺呈現**：A0海報 + 300dpi地圖

## 七、2026年比賽 — 與2025年的異同

| 維度 | 2025年 | 2026年 |
|------|--------|--------|
| 比賽時間 | 4/25-4/28觀察，6/30提交 | **5/18-7/3**（整體時程） |
| 觀察數據量 | 33,571條 | 18,437條（⚠️ 減少45%） |
| 物種數 | 2,994種 | 2,019種 |
| 圈養數據 | 17% | **0%（100%野生）** |
| 植物佔比 | 75.9% | 52.9% |
| 昆蟲佔比 | 8.8% | **20.1%**（大幅增加） |
| 鳥類佔比 | 9.5% | **16.4%**（大幅增加） |

> 🔑 **策略啟示**：2026年數據中動物（尤其昆蟲和鳥類）佔比大幅提升，且全部為野生觀測。這意味著**動物相關的分析方向**（如食物網、傳粉網絡、鳥類-植物互動）將比2025年更有數據支撐。
