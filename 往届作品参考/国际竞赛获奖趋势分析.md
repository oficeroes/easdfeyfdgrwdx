## 一、競賽定位分析

「全澳生物多樣性數據科學挑戰賽」具有以下獨特定位：

| 特徵 | 說明 |
|------|------|
| 數據來源 | 公民科學（iNaturalist平台） |
| 數據類型 | 物種出現記錄（presence-only），含GPS坐標+時間+分類 |
| 分析要求 | 多樣性指數 + 進階數據科學 + 保護建議 |
| 產出形式 | A0海報 + 5分鐘短片 + 300dpi地圖 |
| 參賽者 | 中學生團隊 |

這與以下國際競賽有高度相似性。

## 三、全國青少年科技創新大賽（CASTIC）— 環境科學類

### 3.1 近年優秀項目主題

| 年份 | 項目主題 | 核心方法 |
|------|---------|---------|
| 2024 | 基於公民科學數據的城市蝴蝶多樣性時空格局 | 大數據 + GIS |
| 2023 | 濱海濕地植物功能性狀對鹽度梯度的響應 | 實驗生態學 |
| 2023 | 基於MaxEnt模型的入侵物種適生區預測 | SDM |
| 2022 | 城市熱島效應對昆蟲多樣性的影響 | 環境梯度分析 |
| 2022 | 基於eDNA技術的城市河流魚類多樣性評估 | 分子生態學 |
| 2021 | 校園鳥類群落結構與植物配置的關係 | 群落生態學 |

### 3.2 CASTIC獲獎規律

- **地方特色**：項目與當地生態環境緊密相關
- **方法多元**：不只描述，有建模或統計推斷
- **應用價值**：成果可轉化為實際建議

## 四、City Nature Challenge 全球賽

### 4.1 與本比賽的關係

本比賽的數據收集階段同步於CNC全球賽。2025年澳門在669個城市中取得：
- 觀察量第7名
- 物種數第8名

### 4.2 CNC衍生研究案例

CNC數據已被用於以下學術研究（可作為本比賽的靈感來源）：

| 研究方向 | 方法 |
|---------|------|
| 城市生物多樣性熱點識別 | 空間聚類 + 熱力圖 |
| 不同城市的物種組成比較 | Beta多樣性 + NMDS排序 |
| 公民科學數據質量評估 | 與專業調查數據比對 |
| 城市化梯度對物種豐富度的影響 | GLM/GAM回歸 |
| 季節性對觀測數據的影響 | 時間序列分析 |

## 五、獲獎策略總結

### 5.1 評審視角推測

基於對多個競賽評審標準的分析，推測評審看重的是：

```
創新性 (30%)
├── 方法是否新穎（不只是套用現成工具）
├── 科學問題是否有原創性
└── 是否結合了澳門本地特色

嚴謹性 (25%)
├── 統計方法是否正確
├── 結論是否有數據支撐
└── 是否討論了局限性

完整性 (20%)
├── 從問題→方法→結果→討論→建議的完整鏈條
├── 多維度分析（不只一個角度）
└── 保護建議的可行性

展示性 (25%)
├── 海報的視覺設計和可讀性
├── 地圖的專業性和美觀度
└── 短片的故事性和感染力
```

### 5.2 差異化策略

基於對2025年比賽的分析，2026年團隊應避免：

| ❌ 避免 | ✅ 替代策略 |
|--------|-----------|
| 純描述性分析（只算Shannon指數） | 加入推斷性統計和建模 |
| 只做植物分析（75%的數據是植物） | 利用2026年動物數據增多的特點 |
| 泛泛的「加強保護」建議 | 具體的、可量化的保護方案 |
| 靜態的單年分析 | 2025 vs 2026跨年比較 |
| 只用Excel和基本圖表 | Python/R + 專業GIS製圖 |
