- 數據來源於 **全球城市自然挑戰賽（澳門區）** 的觀察資料與 [iNaturalist.org](https://www.inaturalist.org)

## 📋 欄位結構（共 15 項）

兩個年份的數據包欄位結構完全相同：

| 欄位名稱 | 說明 | 格式／內容範圍 |
|---------|------|-------------|
| `id` | 觀察的唯一編號 | 整數 |
| `observed_on` | 觀察日期（標準格式） | YYYY-MM-DD |
| `time_observed_at` | 觀察具體時間（UTC+8） | h:mm:ss AM/PM |
| `captive_cultivated` | 是否為人工飼養或栽培 | TRUE（是）／FALSE（否） |
| `latitude` | 緯度（觀察地點） | -90 至 90 |
| `longitude` | 經度（觀察地點） | -180 至 180 |
| `iconic_taxon_name` | 高階分類群（如植物、鳥類、昆蟲等） | 文字 |
| `taxon_kingdom_name` | 界（Kingdom） | 文字 |
| `taxon_phylum_name` | 門（Phylum） | 文字 |
| `taxon_class_name` | 綱（Class） | 文字 |
| `taxon_order_name` | 目（Order） | 文字 |
| `taxon_family_name` | 科（Family） | 文字 |
| `taxon_genus_name` | 屬（Genus） | 文字 |
| `taxon_species_name` | 種（Species） | 文字 |
| `taxon_subspecies_name` | 亞種（Subspecies） | 文字（可為空） |

## 📝 注意事項

1. 2026 年原始文件名為 `2026 團隊賽數據包.xlsx`，目前資料夾中實際存在的是 `副本2026 團隊賽數據包.xlsx`（內容相同）
2. 2025 年數據中約 **17% 的記錄為人工飼養或栽培物種**，分析時可能需注意區分
3. 2025 年數據 `longitude` 和 `latitude` 的順序為（經度, 緯度），2026 年為（緯度, 經度），使用時請注意欄位對應
4. 數據來源於公民科學平台 iNaturalist，觀察品質可能參差不齊
