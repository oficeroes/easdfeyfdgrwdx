## 「寻找台北蛙：澳门最稀有本土两栖类的分布预测与保护空缺分析」

> **Searching for the Taipei Frog: SDM Prediction and Conservation Gap Analysis of Macau's Rarest Native Amphibian**

| 维度 | 内容 |
|------|------|
| **研究方向** | B — 气候变化对生物多样性的影响 |
| **往届冲突** | 🟢 **极低** — 2025年两栖类数据极少，SDM技术门槛高，中学生首屆不可能涉及 |
| **核心问题** | 台北蛙（*Hylarana taipehensis*）在2026年仅出现**1次**。其潜在分布区在哪？气候变化将如何影响未来栖息地？当前保护区体系是否覆盖其分布？ |
| **数据支撑** | 台北蛙1次记录 + 其他6种两栖类302次 + GBIF华南地区台北蛙记录 |
| **分析方法** | MaxEnt物种分布模型 → WorldClim气候+地形变量 → 2050/2070未来气候情景预测（SSP2-4.5/SSP5-8.5）→ 保护空缺叠图（GAP analysis） |
| **创新亮点** | ✨ 1次记录做SDM——技术上极具挑战性，展示小样本建模能力 ✨ "生态侦探故事"叙事 ✨ 气候变化+濒危物种+保护建议三重价值 |
| **获奖契合度** | ⭐⭐⭐⭐⭐ ISEF 2024有ML预测物种分布变化获奖。SDM是ISEF/CASTIC高频获奖方法。濒危物种=天然道德号召力 |
| **2025评委新印象** | 🆕 2025年几乎不可能有团队做两栖类SDM（数据量太少+技术门槛高）→ 评审会视为**全新方向** |
| **展示潜力** | 🎨 SDM预测地图+保护空缺叠图；短片可拍成"寻找台北蛙"生态纪录短片 |
| **潜在挑战** | 仅1次记录对MaxEnt建模构成挑战，可能需要与华南地区的台北蛙记录合并建模 |

### 选题二 🌟🌟🌟🌟🌟（强烈推荐）

## 「2025→2026：澳门生物多样性的年度变迁——物种更替、群落重构与保护启示」

> **2025→2026: Annual Biodiversity Turnover in Macau — Species Replacement, Community Reassembly, and Conservation Implications**

| 维度 | 内容 |
|------|------|
| **研究方向** | 跨领域 — 时间生态学 + 群落动态 |
| **往届冲突** | 🟢 **零冲突** — 2025年为首屆比赛，**仅有一年数据**，时间对比分析在物理上不可能 |
| **核心问题** | 两年共有物种仅占2025年物种数的47.0%——真生态变化还是采样偏差？哪些物种"消失"了、哪些"新出现"了？物种更替的空间热点在哪？ |
| **数据支撑** | 2025年33,486条/2,979种；2026年18,367条/2,009种；共有1,399种（占2025物种数47.0%，Jaccard相似度39.0%）；仅2025独有1,580种；仅2026独有610种 |
| **分析方法** | 时间Beta多样性分解（turnover vs nestedness）→ 物种增益/损失空间热点图 → "消失物种"生态特征分析 → 采样校正（rarefaction+Chao2）→ 识别"快速衰退物种" |
| **创新亮点** | ✨ **2026年比赛的独有王牌**——没有任何2025年团队能做 ✨ 区分"真生态变化"vs"采样偏差"→方法论严谨性 ✨ 跨年对比在公民科学比赛中极为罕见 |
| **获奖契合度** | ⭐⭐⭐⭐⭐ ISEF获奖特征中"时间维度分析"被评为关键加分项 |
| **2025评委新印象** | 🆕 评审会直接注意到"这个分析在去年根本不可能做" → **天然护城河** |
| **展示潜力** | 🎨 两年对比地图（红=消失/绿=新增/蓝=稳定）；物种更替桑基图；"消失物种档案" |

### 选题四 🌟🌟🌟🌟🌟（强烈推荐）

## 「澳门鸟类的'日班与夜班'：昼行性与夜行性鸟类的时空生态位分化」

> **Day Shift vs Night Shift: Spatiotemporal Niche Partitioning of Diurnal and Nocturnal Birds in Macau**

| 维度 | 内容 |
|------|------|
| **研究方向** | A — 物种之间的相互作用（生态位分化） |
| **往届冲突** | 🟢 **极低** — 2025年鸟类占9.5%（低于2026年的16.4%），且首屆比赛不太可能做昼夜节律分析 |
| **核心问题** | 澳门95种鸟类中，哪些在白天活动、哪些在夜间/晨昏活动？昼夜鸟类群落在空间利用上有何差异？城市化对不同活动节律鸟类的影响是否不同？ |
| **数据支撑** | 2026年鸟类3,007条正确记录（带time_observed_at时间戳）；95种鸟类；可标注昼夜属性（文献+时间戳验证） |
| **分析方法** | 基于time_observed_at的日活动节律曲线（kernel density estimation）→ 昼夜鸟类空间分布对比（KDE热力图）→ 昼夜生态位重叠指数 → 城市化梯度对昼夜鸟类的影响差异（GLM） |
| **创新亮点** | ✨ **时间生态学**——利用time_observed_at字段的创意应用 ✨ "日班vs夜班"隐喻极好理解 ✨ 几乎没有团队会从这个角度切入鸟类数据 |
| **获奖契合度** | ⭐⭐⭐⭐⭐ 时间维度的生态学分析是ISEF近年新宠 |
| **2025评委新印象** | 🆕 2025年鸟类数据少+首屆比赛方法较基础 → 昼夜生态位分析是评审从未见过的 |
| **展示潜力** | 🎨 昼夜对比地图+"鸟类时钟"24小时活动图谱；短片可对比白天/夜晚的澳门鸟世界 |
| **潜在挑战** | 2026年time_observed_at有约1.8%缺失值 |

## 「澳门昆虫多样性的'大跃进'之谜：2025→2026年昆虫激增现象的驱动因素分析」

> **The Great Insect Surge: Drivers of Insect Diversity Explosion from 2025 to 2026 in Macau**

| 维度 | 内容 |
|------|------|
| **研究方向** | 跨领域 — 群落动态 + 环境驱动 |
| **往届冲突** | 🟢 **极低** — 2025年昆虫占8.7%（2,929条），2026年升至20.0%（3,673条）。2025年昆虫数据相对不突出 |
| **核心问题** | 昆虫占比从8.7%→20.0%，物种数从475→574种。这是真实的群落变化还是采样效应？如果是真的，什么驱动了这一变化？ |
| **数据支撑** | 2025年昆虫2,929条/475种；2026年昆虫3,673条/574种；昆虫目级组成对比（鳞翅目/膜翅目/鞘翅目等） |
| **分析方法** | 2025→2026昆虫目级组成变化（卡方检验）→ 新增昆虫物种的功能特征 → 空间分布变化（哪些区域昆虫增长最多？）→ 采样偏差排除（rarefaction）→ 气候/物候关联分析 |
| **创新亮点** | ✨ 捕捉到可能真实的"昆虫大爆发"信号——极具新闻价值 ✨ 全球昆虫衰退背景下，澳门昆虫反而增加——独特叙事 ✨ 采样分析+生态推断的双重严谨性 |
| **获奖契合度** | ⭐⭐⭐⭐⭐ "昆虫衰退"是近年全球顶级科学话题（Nature/Science频繁发文） |
| **2025评委新印象** | 🆕 2025年昆虫占比极低→昆虫不是当年焦点。2026年昆虫"逆袭"→极具话题性 |
| **展示潜力** | 🎨 昆虫目级组成变化冲积图；2025→2026空间增长动画；短片可讲"昆虫逆袭记" |
| **潜在挑战** | 需审慎区分生态变化vs采样效应（但这本身构成精彩的科学讨论） |
