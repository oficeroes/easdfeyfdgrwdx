## 二、整体生物多样性指数

### 2.1 香农-维纳指数 (Shannon-Wiener Index)

$$H' = -\sum_{i=1}^{S} p_i \cdot \ln(p_i)$$

其中 $p_i = \frac{n_i}{N}$，$n_i$ 为第 $i$ 个物种的个体数，$N$ 为总个体数。

| 指数 | 数值 |
|------|------|
| **香农-维纳指数 H'** | **6.4149** |
| 最大可能值 H'max = ln(S) | 7.6104 |

**解读：** H' = 6.41 是一个非常高的值，表明澳门具有**极丰富**的生物多样性。一般而言，H' > 3 即可视为高多样性生态系统。澳门的 H' 接近理论最大值（7.61），说明物种组成非常丰富。

### 2.2 辛普森多样性指数 (Simpson's Diversity Index)

$$D = \frac{\sum_{i=1}^{S} n_i(n_i-1)}{N(N-1)}$$

| 指数 | 数值 |
|------|------|
| **辛普森指数 D** | 0.004194 |
| **辛普森多样性指数 (1-D)** | **0.995806** |
| **逆辛普森指数 (1/D)** | **238.46** |

**解读：**
- 辛普森指数 D 极低（趋近于 0），说明没有任何单一物种占据绝对优势
- 多样性指数 1-D = 0.996 趋近于 1，再次印证澳门生态系统具有极高的物种多样性
- 逆辛普森指数 238.46 意味着：随机抽取两个个体，它们属于不同物种的概率极高；等效于一个均匀分布的群落中有 238 个等丰富度物种

### 2.3 Pielou 均匀度指数 (Pielou's Evenness)

$$J' = \frac{H'}{H'_{max}} = \frac{H'}{\ln(S)}$$

| 指数 | 数值 |
|------|------|
| **Pielou 均匀度 J'** | **0.8429** |

**解读：** J' = 0.843 表示群落中物种个体数分布较为均匀。均匀度越接近 1，说明优势种越不突出，群落结构越稳定。0.84 属于较高水平。

## 六、综合结论

1. **澳门整体生物多样性极高**：Shannon H' = 6.41，Simpson 1-D = 0.996，在全球城市生态系统中属于顶尖水平
2. **群落均匀度良好**（J' = 0.843）：无极端优势种，生态系统结构健康
3. **路环是生物多样性热点**：具有最高的 Shannon 指数和均匀度，应作为重点保护区域
4. **植物和昆虫是物种丰富度的主要贡献者**：分别贡献了 1,077 和 578 个物种
5. **两年间物种组成差异显著**（重叠率仅 47%），可能需要加强长期监测
