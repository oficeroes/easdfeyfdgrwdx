## 一、核心概念：一个大时钟，一个完整故事

### 1.1 为什么用时钟

澳门是一座"不夜城"。灯光彻夜不息，但有一批生命不是靠灯光活着的——它们有自己的生物钟。

**时钟是最自然的隐喻：**
- 左半圆（6:00→18:00）= 白天，暖色调，鸟类和昆虫的主角时间
- 右半圆（18:00→6:00）= 黑夜，冷色调，两栖类的主场，也是"不夜城压力"的体现
- 时钟外围 = 空间维度，三个光污染梯度区像三层光晕
- 入侵物种 = 嵌入时钟对应时段的小标签，不分昼夜地扩散

### 【中央：大时钟】约50%版面，视觉核心

#### 时钟设计说明

- 正圆形，占海报中央
- 12个时间刻度标注在圆周上（00:00 在顶部，顺时针）
- **左半圆（06:00→18:00）**：暖沙色背景（`#F5F0E5` → `#E8DFD0` 渐变）
- **右半圆（18:00→06:00）**：深松绿背景（`#1E3D3B` → `#2A4A42` 渐变）
- 6:00和18:00位置自然过渡，不做硬切割
- 圆周内画三条活动曲线（鸟类绿、昆虫深绿、两栖深青绿）
- 曲线高度代表该小时的记录数量（各类群按自身峰值归一化）

---

**⏰ 06:00 晨光**

> 晨间128条鸟类记录。珠颈斑鸠、麻雀、红耳鹎——城市还没完全醒来，它们已经开始了。

**⏰ 10:00 鸟类高峰 ← 特别标注**

> **上午10点，鸟类最活跃的时刻。**

> **黄昏是交接班的时刻。**

**⏰ 19:00 两栖类高峰 ← 特别标注**

> **晚上7点，两栖类开始低鸣。**

> 303条两栖类记录里，215条在夜间——占 **71.7%**。

**⏰ 21:00 深夜生态**

> **夜晚不是静止的。**
> 软体动物在21:00达到高峰。
> 夜行昆虫开始活跃：
> 丽叩甲35条、东方水蠊31条、美洲大蠊26条。

---

**⏰ 00:00-05:00 黎明前**

> 深夜到黎明前，夜行生命仍在坚持。

> 它们为什么在夜里被看到？
> **可能是城市灯光在干扰它们的生物钟。**

## 四、配色方案（大地色系·简约暖白风格）

> 设计原则：3-5 色、低饱和度、从自然取色、暖白底、大量留白。
> 参考：国际获奖生态学海报普遍采用 earthy tones，比亮色更专业、更耐看。

| 用途 | 色值 | 色名 | 说明 |
|---|---|---|---|
| **海报背景** | `#FAF8F5` | 暖奶油白 | 非纯白！像宣纸一样温暖 |
| **主文字** | `#3B5245` | 深 forest 绿 | 标题、正文 |
| **白天/鸟类** | `#8FA889` | 鼠尾草绿 | 低饱和，不刺眼 |
| **全天/昆虫** | `#5C8D6F` | 中森林绿 | 稳定、自然 |
| **夜间/两栖** | `#1E3D3B` | 深青绿 | 深夜质感 |
| **关键数字高亮** | `#C8963E` | 琥珀金 | 呼应"不夜城"灯火 |
| **时钟白天背景** | `#F5F0E5` → `#E8DFD0` | 暖沙色渐变 | 柔和过渡 |
| **时钟黑夜背景** | `#1E3D3B` → `#2A4A42` | 深松绿渐变 | 从夜到暗夜 |
| **入侵预警（高）** | `#C4725A` | 陶土红 | 警示但不刺眼 |
| **入侵预警（中）** | `#C8963E` | 琥珀金 | 关注但不恐慌 |
| **保护建议** | `#5C8D6F` | 中森林绿 | 希望、行动 |
| **路环暗夜** | `#2A4A42` | 暗松绿 | 暗夜避难区 |
| **装饰草叶点缀** | `#A8C5A0` | 浅鼠尾草绿 | 极淡，不抢眼 |
| **数据来源/脚注** | `#8B8B8B` | 暖灰 | 低调 |

### 配色要点

1. **绝不用纯黑 `#000000`**：所有"黑色"文字用 `#3B5245`（深绿黑）
2. **绝不用高饱和色**：旧版的 `#8BC34A`（亮黄绿）→ 新版 `#8FA889`（灰调鼠尾草绿）
3. **背景暖白 ≠ 纯白**：`#FAF8F5` 像纸张一样温暖，让绿色更有层次
4. **点缀色极少使用**：琥珀金 `#C8963E` 只用于3个核心数字和关键标注
5. **时钟深色是局部**：不要让整张海报偏暗，白天半圆保持明亮温暖

## 七、与往届作品的差异化

| 往届常见做法 | 我们的做法 |
|---|---|
| 一格一数据，独立模块 | 一个大时钟，串起所有数据 |
| 学术论文式标题 | 问句式标题，引发好奇 |
| "本研究采用…方法" | "我们用了…"——第一人称 |
| 植物为主角（数据多） | 动物为主角（信号更强、更有故事性） |
| 静态单年分析 | 两年对比 + 24小时时间轴 |
| 保护建议泛泛而谈 | 四个具体卡片，每个有数据支撑 |
