## 推荐海报主标题

**澳门生态昼夜曲**

副标题：**谁还按自己的生物钟生活？**

英文副题可写：

**Macau Ecological Nocturne: Biodiversity Turnover, Daily Rhythms, and Urban Night Pressure**

## 核心一句话

2026 年澳门生物多样性记录总量少于 2025 年，但动物界记录增加，昆虫和鸟类占比显著上升；结合昼夜节律、简化光污染梯度和入侵物种预警，可以看到“城市越亮、记录越变、管理越需要精细”的生态信号。
