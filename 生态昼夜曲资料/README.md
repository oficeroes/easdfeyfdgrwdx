# 生态昼夜曲海报报告包

> 文件夹名称按用户要求保留为“生态就业曲”；内容主题为“澳门生态昼夜曲：年度变迁下的不夜城与生物多样性”。

本文件夹用于支撑 2026 年澳门校际团队挑战赛 A0 学术海报、300 dpi 物种空间分布图和 5 分钟科普短片。内容基于项目中的清理后正确数据、专题 CSV、既有分析报告和往届作品参考资料整理，不混用上一年参考作品的数据。

## 文件清单

| 文件 | 用途 |

## 推荐海报主标题

**澳门生态昼夜曲：年度变迁下的不夜城与生物多样性**

英文副题可写：

**Macau Ecological Nocturne: Biodiversity Turnover, Daily Rhythms, and Urban Night Pressure**

## 核心一句话

2026 年澳门生物多样性记录总量少于 2025 年，但动物界记录增加，昆虫和鸟类占比显著上升；结合昼夜节律、简化光污染梯度和入侵物种预警，可以看到“城市越亮、记录越变、管理越需要精细”的生态信号。
