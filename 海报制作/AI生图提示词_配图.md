# 🎨 海报配图 · AI生图提示词

> **风格统一说明**：所有提示词默认使用 **粗粝卡通 / 手绘涂鸦风**——不精致、不过度渲染、像自然笔记或童书草图的感觉。
> 英文风格关键词（可直接加在任何提示词末尾）：
> `rough cartoon style, hand-drawn illustration, sketchy lines, flat colors, gouache texture, children's field notebook style, imperfect edges, no photorealism, no 3D rendering, no detailed shading`
>
> 中文生图工具（如通义万相、文心一格等）建议在末尾加：**粗线条卡通、手绘涂鸦风、扁平色块、不要写实、不要3D、不要精细渲染**

## 🎯 风格参考关键词速查

| 你想要的效果 | 加在提示词末尾 |
|:---|:---|
| 粗线条+色块 | `bold outlines, flat color blocks, no gradient shading` |
| 手绘速写感 | `sketchy hand-drawn, rough pencil lines, field notebook style` |
| 童书但不精致 | `children's book illustration but rougher, naive art style, deliberately unpolished` |
| 水粉/水彩质感 | `gouache texture, watercolor wash, messy brushstrokes` |
| 自然笔记风 | `nature journal aesthetic, field guide doodle, scientific illustration sketch` |
| **拟人化但自然** | `anthropomorphic animals, tiny props, wearing accessories, human-like poses but still animal-shaped, whimsical` |
| 禁止写实 | `no photorealism, no 3D rendering, no hyperdetailed, no realistic feathers` |

## 🎭 拟人化设计逻辑

> 每张图的拟人动作不是随意的——它们服务于生态叙事：

| 时段 | 类群 | 拟人逻辑 |
|:---|:---|:---|
| 🌙 深夜 | 日行性鸟类（鹊鸲、白头鹎等） | **"熬夜的人"**——看报纸、喝咖啡、开台灯。它们不该醒着，是被灯光"骗"了 |
| 🌙 深夜 | 夜行性动物（丽叩甲、黑眶蟾蜍） | **"夜班工人"**——安全帽、头灯、DJ耳机。它们本来就该在夜里工作，这才是自然的 |
| 🌙 凌晨4点 | 全类群 | **"打烊了"**——休息中挂牌、叶子当被子。全城唯一同时休息的时刻 |
| 🌅 清晨 | 鸟类 | **"刚起床的人"**——闹钟、打哈欠、喝咖啡、试音。从睡到醒的自然过渡 |
| ☀️ 上午 | 鸟类+昆虫 | **"音乐节/工作日常"**——指挥棒、麦克风、公文包、购物袋。全城生态最活跃的时刻 |

## 📐 建议尺寸

| 用途 | 建议比例 | 说明 |
|:---|:---|:---|
| 时钟背景大图 | `16:9` 横版 | 放在钟面后面做底 |
| 物种特写卡片 | `3:4` 竖版 | 配合数据卡使用 |
| 方形图标 | `1:1` | 物种头像/小图标 |
| 宽幅场景 | `21:9` 超宽 | 钟面外围环绕带 |

> 💡 **使用建议**：同一时段的多张图尽量用同一个模型/同一个seed变体生成，保持风格一致。如果一次生成太精致，加大 `sketchy, rough, imperfect` 权重；如果太潦草，加一点点 `clean lineart` 平衡。
