## 二、四个行动卡片

### 卡片1 🌃 暗夜友好照明

```
┌─────────────────────────────────────────┐
│                                         │
│   🌃 行动一：推广暗夜友好照明              │
│                                         │
│   问题：                                  │
│   · 90条日行鸟类夜间记录——被灯光"骗"了     │
│   · 半岛鸟类夜间比例3.0%，路环6.2%         │
│   · Science论文：光污染延长鸟类活动50分钟   │
│                                         │
│   建议：                                  │
│   ✅ 公园和湿地周边使用暖色温LED（≤3000K）  │
│   ✅ 路灯加装遮光罩，减少向上散射           │
│   ✅ 深夜（00:00-05:00）调暗非必要照明      │
│   ✅ 参考国际暗天协会（IDA）暗夜友好标准     │
│                                         │
│   📎 IDA: darksky.org                    │
│                                         │
└─────────────────────────────────────────┘
```

**为何与数据直接关联**：
> 本研究数据显示：鸟类记录夜间比例随光污染减少而上升（半岛3.0%→路环6.2%）。Pease & Gilbert (2025, *Science*) 的科学证据直接支撑"减少夜间照明可缓解对鸟类生物钟的干扰"。
