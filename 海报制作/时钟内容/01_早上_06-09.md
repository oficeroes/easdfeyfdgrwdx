# 🌅 06:00-09:00 早上 — 渐强序曲

> **时钟左下方，6点到9点方向。**
> 深夜的疑问之后，天亮了。这是答案的第一章。
> 鸟鸣从18条涨到56条、54条——清晨不是爆发，是渐强。

**色调**：暖沙色渐变 `#F5F0E5` → `#E8DFD0`，模拟晨光渐亮  
**类群焦点**：🐦 鸟类（绝对主角），昆虫刚开始热身  
**功能**：**承接深夜的疑问，给出第一个答案**——天亮后，生物钟回来了  
**情绪关键词**：苏醒、鸟鸣、渐强、露水、城市将醒未醒

## 三、叙事正文（主版，~200字）

> **06:00。天刚蒙蒙亮。**
> 
> 赌场的霓虹还没熄，街灯仍亮着——但太阳已经在地平线下了。
> 深夜开场里我们问的那个问题——"谁还按自己的生物钟生活？"——
> 天亮后的第一个答案，是鸟给的。
> 
> **06:00，18条鸟类记录。** 不多，但这是整座城市一天里最早的生态信号。
> 珠颈斑鸠在06:10发出第一声咕咕——低沉、重复、像在试探天是不是真的亮了。
> 鹊鸲在06:18开始清唱。红耳鹎在06:28加入——头上那撮冠羽在晨光里微微颤动。
> 小白腰雨燕在06:20掠过天空，用翅膀划开澳门的黎明。
> 
> **07:00，56条记录——翻了三倍。08:00，54条。**
> 鸟鸣像涟漪一样在澳门扩散：从路环的山坡到氹仔的湿地，从半岛的公园到街边的榕树。
> 三个小时，128条鸟类记录。而昆虫呢？只有41条——还没热起来，在等太阳。
> 两栖类3条——夜班刚下班，正在找地方躲。
> 
> **清晨是鸟的独奏。其他类群还在排队等登场。**

## 五、物种特写

### 🕊️ 珠颈斑鸠 — "报晓者"

```
06:10，第一声。
06:22，第二次。
06:26，第三次。
06:47，第四次。

清晨6点这一个小时里，珠颈斑鸠被记录了4次。
它是澳门2026年记录最多的物种（484条），
也是最早醒来的鸟。

脖子上那圈黑白斑点，像一串念珠——
澳门人叫它"咕咕"。
```

### 🎵 鹊鸲 — "晨间歌手"

```
06:18，鹊鸲开始唱歌。

黑白分明，像穿着燕尾服的歌者。
它是澳门最会唱的鸟之一。
有趣的是：它在深夜也被记录了14次——
是所有鸟类夜间记录最多的。

也许它是被路灯"骗"了，
也许它只是比别人更早醒来。
```

### 🔴 红耳鹎 — "冠羽信号"

```
06:28，红耳鹎加入。

头上那撮立起来的冠羽，脸颊一抹红色——
澳门最好认的鸟之一。
246条记录，排名第四。
喜欢站在枝头最高的地方，
好像在宣布：这一天，开始了。
```

### ✈️ 小白腰雨燕 — "天空跑者"

```
06:20，掠过天空。

吃东西在空中，喝水在空中，连睡觉都在飞。
清晨6点的澳门天空，是它的跑道。
```
