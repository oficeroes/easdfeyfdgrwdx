## 一、核心论点

```
┌─────────────────────────────────────────────────┐
│                                                 │
│   💡 人造光正在改写澳门生物的空间分布               │
│                                                 │
│   路环（暗）→ 夜行生命的热闹派对  37.6%夜间活动     │
│   半岛（亮）→ 日行鸟在路灯下"熬夜" 16.9%           │
│                                                 │
│   光越少的地方，按自己生物钟生活的生命越多。         │
│                                                 │
└─────────────────────────────────────────────────┘
```

**学术依据**：
> Pease & Gilbert (2025, *Science*) 证明光污染使鸟类发声活动延长50分钟。Owens & Lewis (2018) 综述了ALAN对夜行昆虫的广泛影响。我们的数据在澳门尺度上呈现了一致的空间模式。

## 四、⚡ 关键问题：为什么中高光区夜间比例最低？

> 这是本数据集中最反直觉的发现——氹仔/路氹城的光污染介于半岛和路环之间，但夜间活动比例反而最低（5.3%）。

### 科学解释（三个不互斥的假说）

**假说一：生境可用性差异（最可能的解释）**

氹仔/路氹城由填海地和城市开发区组成，缺乏夜行焦点类群所需的湿地、森林等自然生境。两栖类在氹仔/路氹城仅有44条记录，而路环有204条。夜间比例低可能主要反映**夜行物种的生境缺失**，而非光本身的直接效应。

> *Gaston et al. (2013) 指出：光污染与生境丧失经常共同发生，需要区分两者的贡献。*

**假说二："光屏障"回避效应**

氹仔/路氹城的大型赌场度假村（威尼斯人、永利皇宫、伦敦人等）使用极高亮度的LED照明。这种极端光照可能形成"光屏障"——一些夜行物种完全回避这些区域，而不是在区域内增加夜间活动。即光太亮时，敏感物种不是"熬夜"，而是**直接离开**。

> *Wikipedia: "一些蜘蛛回避亮区，另一些直接利用灯柱结网——不同物种对光的响应差异巨大（Czaczkes et al., 2018）。"*

**假说三：公民科学观察偏倚**

公民科学家在高强度城市区进行夜间观察的可能性和便利性可能低于白天。路环作为郊野公园吸引了更多专程的夜间自然观察者。

### 在海报上的表述

> 💡 "中高光区夜间活动比例最低，提示光污染对生物的影响不是简单的线性关系——极端光照可能形成'光屏障'，使夜行物种完全回避，而非增加夜间活动。**这一问题本身就值得写入海报，展示科学思维的严谨性。**"
