# 🗺️ 数据区：空间分析 — 光污染梯度

> **时钟下半部分 · 中栏** — 回答"光污染在空间上如何影响生物钟？"
> 约A0海报20%版面

## 一、正文

**① 澳门：32.9km²的生物多样性热点**

澳门陆地面积仅32.9平方公里，却是货真价实的生物多样性热点。2025年我们记录了2,979个物种、33,486条观测；2026年为2,009个物种、18,367条观测。两组数据的香农-维纳指数（Shannon H'）分别达到6.71和6.41——在城市生态学中，H'超过6已属极高水平的物种多样性。辛普森多样性指数（Simpson 1-D）两年均超过0.995，意味着随机抽取两条记录，它们属于不同物种的概率接近100%——没有单一物种形成绝对垄断。Pielou均匀度指数两年均高于0.84，说明记录在物种间的分布相当均匀，并未高度集中于少数优势种。从植物、昆虫、鸟类、两栖类、爬行类、鱼类、软体动物、蛛形纲到哺乳类和真菌，两年共涵盖超过11个生物大类群。这片土地虽然比很多大学校园还小，但生命在这里的密度和丰富度，远超直觉所能想象。

**② 澳门的光并非均匀分布——一条天然的"光污染梯度"**

然而，澳门的光环境与它的生物多样性一样，存在显著的空间差异。澳门半岛是密集的老城区，街灯与商业照明交织成持续的高亮度环境；氹仔和路氹城区域集中了大型度假村的极端LED光群；而路环岛保留了相对完整的山林和湿地，夜间光照显著低于其他区域。这种从"不夜"到"暗夜"的天然过渡，为检验一个关键假说提供了理想条件：**光污染是否在改写澳门生物的空间分布与昼夜节律？** 我们将2026年的有效记录按简化光污染梯度分为三层——高光区（半岛）、中高光区（氹仔·路氹城）和相对低光区（路环），将夜行焦点类群（昆虫、两栖类、软体动物、蛛形纲）和鸟类的昼夜活动模式进行了跨区比较。

**③ 梯度数据说话：光越暗，按自己生物钟生活的生命越多**

结果呈现了一个清晰的方向：夜行焦点类群在路环相对低光区的夜间活动比例为37.6%，是半岛高光区16.9%的2.2倍。若拆分到具体类群——鸟类的夜间活动比例在路环为6.2%，半岛仅为3.0%；昆虫的夜间比例在路环达31.0%，半岛为13.8%，差距达2.2倍。两栖类的空间集中更为极端：2026年共记录303条两栖类数据，其中204条集中在路环，半岛仅55条，而两栖类整体夜间活动比例高达71.7%。**路环，这座7.6平方公里的岛屿，正在成为澳门夜行生命最后的暗夜避难所。** 然而这个避难所并非固若金汤——随着路氹城填海区持续开发，光晕正在从北侧逐渐渗透。

**④ 中高光区的反直觉发现：光污染的影响不是简单线性**

数据中有一个值得深究的"反常"：氹仔/路氹城的中高光区，夜行焦点类群夜间比例仅为5.3%——不是介于半岛和路环之间的"中间值"，而是三区中的最低值。这与"光越亮夜间活动越少"的简单线性预期不符。我们提出三个不互斥的假说：其一，**生境缺失效应**——氹仔/路氹城以填海地和城市开发区为主，缺乏湿地和森林等夜行物种所需生境，该区两栖类仅44条记录（路环为204条），夜间比例低可能主要反映"没有夜行物种可记录"而非"光直接抑制了活动"（Gaston et al., 2013）；其二，**光屏障回避效应**——该区域大型度假村的极端LED亮度可能形成"光屏障"，使敏感夜行物种完全回避该区域，而非在区域内增加夜间活动（Czaczkes et al., 2018）；其三，**公民科学观察偏倚**——市民在高强度城市区进行夜间观察的意愿和便利性可能低于白天。

这三个假说共同指向一个更深层的认识：**光污染对生物的影响不是简单的线性关系，极端光照可能导致物种回避而非活动延长。** 路环37.6%与半岛16.9%的差距，以及中高光区5.3%的谷底值，共同构成了澳门昼夜生态空间的完整图景——光越少的地方，按自己生物钟生活的生命越多；但当光强到一定程度，生命不是"熬夜"，而是离开。
