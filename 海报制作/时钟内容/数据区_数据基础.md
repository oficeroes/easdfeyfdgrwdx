## 一、核心数据卡片

### 卡片1：两年数据一览

```
┌─────────────────────────────────────────┐
│                                         │
│   2025年              2026年            │
│   33,486 条            18,367 条         │
│   2,979 种             2,009 种          │
│                                         │
│   总记录 ↓45%，但——                     │
│   动物界记录反而 ↑8.8%                   │
│                                         │
│   Jaccard 物种相似度：39.0%              │
│   → 两年物种组成差异明显                 │
│                                         │
└─────────────────────────────────────────┘
```

**一句话**：2026年不是"变少了"，是**动物的声音更清楚了**。

### 卡片2：类群结构变了

```
┌─────────────────────────────────────────┐
│                                         │
│         2025年         2026年            │
│   植物  76.0%  →  53.0%  ↓23pp          │

│   两栖   0.6%  →   1.6%  ↑1.0pp         │
│                                         │

│                                         │
└─────────────────────────────────────────┘
```

**一句话**：昆虫和鸟类是2026年澳门城市生态的**绝对主角**。

---

### 卡片3：为什么鸟和虫是焦点？

| 焦点头衔 | 鸟类 | 昆虫 |
|:---|:---|:---|
| 记录量 | 3,007条 | 3,673条 |
| 占比 | 16.4% | 20.0% |
| 物种数 | 95种 | 574种 |
| 日/夜属性 | 日行为主（96.9%白天） | 白天强但夜不停（18.7%夜间） |
| 高峰时刻 | ⏰ **10:00** (378条) | ⏰ **15:00** (487条) |
| Top1物种 | 珠颈斑鸠 484条 | 丽叩甲 35条(夜间) |

**学术依据**：
> 鸟类是光污染研究的核心模式类群。Pease & Gilbert (2025, *Science*) 使用全球583种日行鸟类的6000万条声学记录证明：**光污染使鸟类发声活动平均延长50分钟**。昆虫对夜间人造光（ALAN）的敏感性已被大量研究证实（Owens & Lewis, 2018）。

## 二、方法简图

```
原始数据 (52,218条)
    │
    ├─→ 坐标清洗 → 剔除155条异常坐标
    │
    ▼
正确数据 (51,853条)
    │
    ├─→ 多样性指数：Shannon H'、Simpson D、Pielou J'
    ├─→ 年际比较：Jaccard相似度、共有/独有物种
    ├─→ 昼夜分箱：夜间(19-05) / 晨间(06-08) / 白天(09-16) / 黄昏(17-18)
    ├─→ 光污染梯度：高光(半岛) / 中高光(氹仔路氹城) / 相对低光(路环)
    └─→ 保护建议：入侵预警 + 暗夜照明
```

## 三、数据边界声明（脚注小字）

> ⚠️ 本研究使用公民科学观测数据。两年记录差异可能部分来自观测人数、路线、季节和关注类群的变化。"独有物种"仅代表当年被记录，不代表真实新增或消失。Shannon指数2026年(6.41)略低于2025年(6.71)，但Simpson 1-D两年均接近1（无单一物种绝对主导），Pielou均匀度2026年(0.843)略高于2025年(0.838)。
