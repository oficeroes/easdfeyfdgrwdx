## 一、研究思路流程图（可直接复制上版）

**研究思路**

**📊 两年数据**  →  **🧹 坐标清洗**  →  **🕐 昼夜分箱**  →  **🗺️ 梯度比较**  →  **💡 保护建议**

| 步骤 | 内容 | 方法说明 |
|:---|:---|:---|
| **📊 两年数据** | 收集2025与2026年澳门生物多样性公民科学观测数据 | 原始记录52,218条，来自团队赛数据包 |
| **🧹 坐标清洗** | 剔除155条坐标异常记录，区分圈养/野生，统一分类体系 | 坐标落点验证 + 澳门陆域边界比对 |
| **🕐 昼夜分箱** | 将51,853条有效记录按观测时间分为四段 | 夜间(19-05) / 晨间(06-08) / 白天(09-16) / 黄昏(17-18) |
| **🗺️ 梯度比较** | 按简化光污染梯度比较不同区域的昼夜活动模式 | 高光区(半岛) / 中高光区(氹仔路氹城) / 相对低光区(路环) |
| **💡 保护建议** | 基于时空分析结果提出可执行的保护行动 | 暗夜友好照明 + 路环暗夜示范区 + 入侵物种年度预警 |

**分析工具**：Shannon H' · Simpson D · Pielou J' · Jaccard相似度 · 类群占比 · 昼夜节律曲线

## 四、分析工具速查

| 工具 | 用途 | 海报中何处使用 |
|:---|:---|:---|
| Shannon H' | 综合多样性（丰富度+均匀度） | 数据基础栏 |
| Simpson 1-D | 随机两记录属于不同物种的概率 | 数据基础栏 |
| Pielou J' | 均匀度（是否集中于少数种） | 数据基础栏 |
| Jaccard相似度 | 两年物种组成重叠度 | 核心数字条：39.0% |
| 昼夜分箱 | 区分各类群的日/夜活动模式 | 时钟曲线 + 空间分析 |
| 光污染梯度 | 比较不同光环境下的生态信号 | 空间分析栏核心 |
